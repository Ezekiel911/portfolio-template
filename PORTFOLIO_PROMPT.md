# Portfolio Site Prompt

Use this prompt when customizing or rebuilding the portfolio template:

> Build and refine this repository-ready portfolio as a privacy-safe starter, not as a claim of someone's real identity or employment. Use static HTML, CSS utility classes, and vanilla JavaScript. Do not add a backend, analytics, tracking, form submission, or personal-data collection unless explicitly approved.
>
> Replace every "Your Name", "YN", "Project One", "Project Two", "Project Three", placeholder description, and `#` link with the user's explicitly approved information. Do not infer age, location, education, employers, certificates, metrics, testimonials, repositories, or project outcomes.
>
> Use no direct email, phone number, postal address, private account, personal photo, biometric image, government ID, or hidden metadata. Keep the template usable before customization: neutral identity, neutral project imagery, visible labels for placeholders, and no broken controls.
>
> Produce a responsive Experience-mode portfolio with strong hierarchy, real approved imagery, restrained motion, visible keyboard focus, contrast, light/dark themes, reduced-motion support, and a no-JavaScript-safe baseline. Avoid decorative gradients, generic icon cards, fake dashboards, invented claims, and social-only filler.
>
> Make project filters, dialogs, screenshot viewing, mobile navigation, theme switching, and every remaining link work. Remove controls that do not have a real destination instead of inventing a placeholder action.
>
> Before completion, inspect desktop and mobile layouts, test keyboard and reduced-motion behavior, check browser errors and asset paths, scan every source and asset for personal data or secrets, verify all links, update README setup/deployment instructions, and document only approved customization fields.
